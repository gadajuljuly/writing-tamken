# مسابقة الكتابة · תחרות הכתיבה

تطبيق ويب لإدارة مسابقتين مستقلتين للكتابة:

- **مسابقة الكتابة في مدارس تمكين – قلم** (واجهة عربية)
- **תחרות הכתיבה** (واجهة عبرية)

زر اللغة في أعلى الصفحة ينقلك بين المسابقتين. بيانات كل مسابقة منفصلة تمامًا عن الأخرى.

## ماذا يوجد في التطبيق

| القسم | ما الذي يفعله |
|---|---|
| الرئيسية | نسبة إنجاز عامة واحدة، وعدد المهام المنجزة وقيد التنفيذ والتي لم تبدأ، وآخر المحاضر وآخر التحديثات |
| قائمة المهام | ستة محاور، وزر «+ إضافة مهمة أخرى» في نهاية كل محور. لكل مهمة: عنوان ووصف، ومسؤول واحد أو أكثر، وحالة بثلاثة ألوان، وملاحظات بجانب المهمة، ومرفقات وصور وروابط واقتراحات، وتاريخ إضافة وتاريخ إنجاز يُسجَّلان تلقائيًا، وخيار «تم اعتماد الاقتراح» |
| محاضر الاجتماعات | رفع ملف PDF أو Word، أو لصق نص WhatsApp، أو كتابة المحضر مباشرة. تنظيم المحضر ومراجعته واعتماده، والاحتفاظ بنسخه السابقة واسترجاعها، والأرشفة، والبحث |
| استخراج المهام | الذكاء الاصطناعي يقترح المهام ومحاورها، ويضع ما لا يُصنَّف في «مهام أخرى». من رفع المحضر يراجع المهام المقترحة ويوافق عليها، فتُضاف عندها فقط. يمنع التطبيق التكرار، ويربط كل مهمة بمحضرها |
| سجل التعديلات | من عدّل، ومتى، وما الذي تغيّر |
| العمل الجماعي | حساب مستقل لكل عضو، وصلاحيات متساوية، وحفظ تلقائي دائم، ومزامنة بين المستخدمين كل بضع ثوانٍ |

**قاعدة الاعتماد:** المحضر والمهام المستخرجة منه لا تُعتمد إلا بموافقة الشخص الذي رفعه. يستطيع أي عضو تعديل المسودة، لكن التعديل يبقى «بانتظار الاعتماد» حتى يوافق عليه رافع المحضر.

## التقنيات

- **Next.js 15** (TypeScript)
- **PostgreSQL** لحفظ البيانات بشكل دائم. محليًا يعمل التطبيق بلا أي إعداد على قاعدة PGlite مدمجة تُحفظ في `./.data`.
- **الملفات** (PDF وWord والصور) تُحفظ داخل قاعدة البيانات، ولا يصل إليها إلا عضو مسجّل الدخول. الحد الأقصى 4MB للملف.
- **الذكاء الاصطناعي:** Claude من Anthropic، عبر `@anthropic-ai/sdk` مع مخرجات JSON منظّمة. النموذج الافتراضي `claude-opus-5-5`.

## التشغيل محليًا

```bash
npm install
```

```bash
npm run dev
```

افتح <http://localhost:3000> وأنشئ حسابًا. في وضع التطوير رمز اللجنة هو `dev`.

## الاختبارات

```bash
npm run build
```

```bash
npm test
```

الاختبارات (Playwright) تغطي ما يلي:

- إضافة المهام وإسنادها لعدة مسؤولين
- تغيير الحالات ومزامنتها بين مستخدمَين
- حساب نسبة الإنجاز
- الملاحظات بعد الإنجاز
- المرفقات
- رفع المحاضر (txt وWord وPDF وWhatsApp)
- استخراج المهام وإضافتها بعد الموافقة فقط، ومنع غير الرافع من الاعتماد
- منع التكرار
- النسخ والاسترجاع والأرشفة والبحث
- توثيق اعتماد الاقتراح في المحضر
- التبديل بين المسابقتين دون اختلاط البيانات

> **تنبيه صريح:** في الاختبارات يُستبدل الذكاء الاصطناعي ببديل ثابت (`AI_MOCK=1`، ويظهر في الواجهة كـ TEST MODE). لذلك تثبت الاختبارات أن مسار المراجعة والموافقة يعمل، لكنها **لا** تثبت جودة تنظيم المحضر بالذكاء الاصطناعي الحقيقي. هذه الميزة لم تُجرَّب بعد مع مفتاح حقيقي، وتحتاج تجربة بعد إضافة `ANTHROPIC_API_KEY`.

## النشر (Vercel + Neon، كلاهما مجاني للبداية)

1. **قاعدة البيانات:** أنشئ مشروعًا في <https://neon.tech> (أو Supabase) وانسخ رابط الاتصال `postgresql://…`. الجداول تُنشأ تلقائيًا عند أول تشغيل.
2. **الاستضافة:** في <https://vercel.com> اختر **Add New → Project** واستورد المستودع `writing-tamken`.
3. أضف متغيّرات البيئة في **Settings → Environment Variables**:

| المتغيّر | إلزامي؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL |
| `AUTH_SECRET` | نعم | نص عشوائي طويل لتوقيع جلسات الدخول (مثلًا ناتج `openssl rand -base64 32`) |
| `SIGNUP_CODE` | نعم | رمز اللجنة. من يعرفه فقط يستطيع إنشاء حساب. أرسله لأعضاء اللجنة |
| `ANTHROPIC_API_KEY` | اختياري | مفتاح من <https://console.anthropic.com> لتفعيل تنظيم المحاضر واستخراج المهام. بدونه يعمل كل شيء، لكن التنظيم وإضافة المهام يدويّان |
| `ANTHROPIC_MODEL` | اختياري | لتغيير النموذج (الافتراضي `claude-opus-5-5`) |

4. اضغط **Deploy**. كل عضو يفتح الرابط، ويضغط «عضو جديد؟ أنشئ حسابًا»، ويُدخل رمز اللجنة.

## الشعار

يكفي وضع ملف الشعار باسم `public/logo.png` (أو `logo.svg`) ليظهر تلقائيًا أعلى الموقع في المسابقتين.
