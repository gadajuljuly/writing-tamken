# مسابقة الكتابة · תחרות הכתיבה

אפליקציית ווב לניהול שתי תחרויות כתיבה נפרדות:

- **مسابقة الكتابة في مدارس تمكين – قلم** (ממשק בערבית)
- **תחרות הכתיבה** (ממשק בעברית)

כפתור השפה מעביר בין שתי התחרויות, והנתונים של כל תחרות נפרדים לגמרי.

**איך זה בנוי:** האתר עולה מ־**GitHub Pages**, בדיוק כמו תכנית העבודה. הנתונים, הקבצים וההתחברות נמצאים ב־**Supabase**. הבינה המלאכותית (Claude) רצה בפונקציה של Supabase. אין שרת נוסף, והכול בחינם.

## מה יש באפליקציה

| חלק | מה הוא עושה |
|---|---|
| ראשי | אחוז ביצוע כללי אחד; מספר המשימות שבוצעו, בביצוע ולא התחילו; הפרוטוקולים והעדכונים האחרונים |
| רשימת משימות | 6 צירים, ובסוף כל ציר כפתור «+ הוספת משימה נוספת». לכל משימה: כותרת ותיאור, אחראי אחד או יותר, סטטוס בשלושה צבעים, הערות לצד המשימה (אפשר לערוך גם אחרי שבוצעה), קבצים, תמונות, קישורים והצעות, תאריך הוספה ותאריך ביצוע אוטומטיים, ו«ההצעה אושרה» עם תיעוד בפרוטוקול |
| פרוטוקולים | העלאת PDF או Word, הדבקת WhatsApp או כתיבה ישירה. אפשר לארגן את הפרוטוקול, לבדוק אותו ולאשר אותו. יש גרסאות קודמות ושחזור, ארכיון וחיפוש |
| חילוץ משימות | הבינה המלאכותית מציעה משימות ואת הציר של כל אחת. משימה שלא מתאימה לשום ציר נכנסת ל«משימות אחרות». המשימות נוספות לרשימה רק אחרי אישור של מי שהעלה את הפרוטוקול. משימות כפולות נחסמות, וכל משימה מקושרת לפרוטוקול שלה |
| יומן שינויים | מי שינה, מתי ומה |
| עבודה משותפת | חשבון לכל חבר ועדה (ההרשמה דורשת קוד ועדה), הרשאות שוות לכולם, שמירה קבועה, ועדכון מיידי אצל כל המשתמשים |

כל ההרשאות נאכפות בתוך Supabase, בקובץ `supabase/schema.sql`. אפשר להשתמש בפרויקט Supabase קיים: כל הטבלאות מתחילות ב־`wt_` ולא נוגעות בטבלאות של אפליקציות אחרות.

## התקנה (פעם אחת)

### 1. Supabase: בסיס הנתונים
1. ב־Supabase נכנסים לפרויקט (חדש או קיים), ואז ל־**SQL Editor** ולוחצים **New query**.
2. מעתיקים את כל התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) ומדביקים אותו.
3. בשורה שמסומנת `CHANGE-ME` מחליפים את `CHANGE-ME` בקוד הוועדה שתבחר, למשל `qalam2026`.
4. לוחצים **Run**. אמורה להופיע ההודעה "Success".

### 2. Supabase: התחברות
1. נכנסים ל־**Authentication**, ואז ל־**Sign In / Providers**, ואז ל־**Email**.
2. כדי שההרשמה תהיה פשוטה יותר, אפשר לכבות את **Confirm email**. אם האפשרות נשארת דלוקה, כל חבר ועדה יאשר את כתובת המייל שלו בפעם הראשונה.

### 3. Supabase: בינה מלאכותית (לא חובה)
1. נכנסים ל־**Edge Functions**, לוחצים **Deploy a new function** ובוחרים **Via Editor**.
2. בשם הפונקציה כותבים `organize-minutes`, מדביקים את התוכן של [`supabase/functions/organize-minutes/index.ts`](supabase/functions/organize-minutes/index.ts) ולוחצים **Deploy**.
3. נכנסים ל־**Edge Functions**, ואז ל־**Secrets**, ומוסיפים `ANTHROPIC_API_KEY` עם מפתח מ־https://console.anthropic.com

בלי השלב הזה האפליקציה עובדת במלואה, רק שהסידור של הפרוטוקול והוספת המשימות נעשים ידנית.

### 4. חיבור האתר ל־Supabase
בקובץ [`.env.production`](.env.production) כותבים את **Project URL** ואת **anon public key** (נמצאים ב־**Project Settings**, תחת **API**). שני הערכים האלה ציבוריים, ומותר לשמור אותם במאגר.

### 5. GitHub Pages
1. במאגר ב־GitHub נכנסים ל־**Settings**, ואז ל־**Pages**.
2. תחת **Source** בוחרים **GitHub Actions**.
3. בכל עדכון של הענף `main` האתר נבנה ועולה מחדש אוטומטית, לכתובת `https://gadajuljuly.github.io/writing-tamken/`

### 6. לוגו
אם שמים קובץ בשם `public/logo.png`, הוא מופיע בראש האתר בשתי התחרויות.

## פיתוח ובדיקות

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

`npm test` מריץ בדיקות על בסיס הנתונים: כל ה־SQL, ההרשאות והפונקציות, מול PostgreSQL מקומי עם תחליף ל־auth של Supabase. הבדיקות מכסות:
- קוד ההצטרפות לוועדה, ושמי שלא חבר ועדה לא רואה כלום
- משימות ותאריך ביצוע
- חסימת משימות כפולות, גם כשהכתיב שונה מעט
- הפרדה בין שתי התחרויות
- יומן השינויים
- רשימת האחראים: קבועה בערבית, ובעברית אפשר להוסיף שמות
- משימות מוצעות מפרוטוקול ואישורן רק על ידי מי שהעלה אותו
- גרסאות, שחזור, ארכיון, חיפוש ותיעוד הצעות שאושרו
- קישורים בטוחים

**עדיין לא נבדק:** האפליקציה מקצה לקצה מול Supabase אמיתי, והבינה המלאכותית מול Claude אמיתי. את שניהם צריך לבדוק אחרי ההתקנה.
